# Navigation commerciale du Cockpit

- **Aujourd’hui** (`/today`) : file d’appels personnelle, filtrée par attribution Cockpit et fenêtre 08:00–19:00 dans le fuseau du prospect, avec état Allo.
- **Appels** (`/prospection`) : prospection et sessions détaillées.
- **Prospects** (`/prospects`) : vue globale de tous les leads/contacts synchronisés dans le Cockpit.
- **Analyse** (`/analytics`) : performance.

La navigation secondaire conserve Sourcing, Segments, Tâches et Rendez-vous. Le style est volontairement léger, proche d’Allo : sidebar gris-vert très clair, icônes 17 px, état actif doux et canvas principal blanc.
